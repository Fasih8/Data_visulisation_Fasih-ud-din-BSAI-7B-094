# Week 1 Data Visualization Assignments

Five separate Jupyter notebooks for the Week 1 data visualization assignment.

## Contents

- `task1_datasaurus.ipynb` — summary statistics and the Datasaurus Dozen scatter plots
- `task2_gapminder.ipynb` — country and continent trends, GDP distribution, and the rich–poor gap
- `task3_penguins.ipynb` — distributions, relationships, missing data, and Simpson's paradox
- `task4_mpg.ipynb` — five questions answered with appropriate chart types
- `task5_flights.ipynb` — monthly passenger trends and seasonality

## Run

Open a notebook in Jupyter and run its cells from top to bottom. Each notebook loads its CSV from the public source URL, so an internet connection is required. The notebooks use Python with `pandas`, `numpy`, and `matplotlib`.
